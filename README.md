# Вокруг света за 80 дней

Первый онлайн-прототип настольной игры.

## Уже работает
- Создание комнаты и вход по шестизначному коду
- До 6 игроков в одной комнате
- Общий маршрут по городам
- Ходы по очереди и бросок кубика
- Синхронизация состояния через Cloudflare D1

## Запуск локально
Установи Wrangler и выполни `wrangler dev`. D1 binding называется `DB`.

## Публикация
Worker развёрнут в Cloudflare Workers: https://around-the-world-80-days.casual-online.workers.dev
